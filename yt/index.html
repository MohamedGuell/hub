Comment obtenir une clé gratuite (3 minutes)
  1. Ouvrir console.cloud.google.com et créer un projet.
  2. Menu « API et services » → « Bibliothèque » → activer YouTube Data API v3.
  3. « Identifiants » → « Créer des identifiants » → Clé API.
  4. Restreindre la clé au site puis la coller ici.
